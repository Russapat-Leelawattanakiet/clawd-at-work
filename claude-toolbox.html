Behind the scenes

What really happens inside Claude

Helper's report

CLAUDE.md

When it starts
By itself, at the start of every chat.
What gets added
Its whole text goes into the notebook.
How long it stays
All chat long, even after /compact. It takes up space on every turn, so keep it short.

It is advice, not a lock.

Skill

When it starts
You type /its-name, or your ask matches its description.
What gets added
The full recipe, as one message. Any commands inside it run first and fill in their results.
How long it stays
For the rest of the chat. Before that, only its menu line is there.

Its extra files are read only if the recipe says so.

Helper agent

When it starts
Claude hands over a job that matches its description, or you @-mention it.
What gets added
Nothing to your notebook while it works. It gets a fresh notebook of its own.
How long it stays
Only its final report comes back to you.

It does not see your chat, only the task.

Hook

When it starts
When an event happens, like a file being edited.
What gets added
Usually nothing. Claude Code runs the code itself.
How long it stays
It just runs each time. It can block an action, which a written rule cannot promise.

This is the way to make a rule a lock.

  1. Already in the notebookCLAUDE.md, the memory notes, the tool names and the skill menu.
  2. Your message goes in“Review my changes.”
  3. Claude picks a toolA skill adds its recipe, or a helper gets a task and sends back one report.
  4. While it worksFolder rules load when it touches those files, and hooks may run.
